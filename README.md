# Brutto-Netto-Rechner 2026

Brutto-Netto-Rechner für Deutschland (Rechtsstand 2026). Die Berechnung läuft
vollständig im Browser, ohne Cookies, ohne Tracking und ohne externe Requests.

Der verbindliche Implementierungsplan steht in [`docs/PLAN.md`](docs/PLAN.md).
Dieses README wird in Phase P7 vervollständigt.

## Entwicklung

Voraussetzung: Node.js ≥ 22.

```sh
npm ci
npm test
```
